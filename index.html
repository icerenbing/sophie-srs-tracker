☁ 云端同步设置

token 是什么？ 它是 GitHub 给你的一串"钥匙"（相当于临时密码），让本工具能往你的 GitHub 私密存一个备忘录（Gist）。只需生成一次、粘贴进来，之后每次点「☁ 同步」就会把电脑和手机的数据合并成同一份。没有 GitHub 账号？去 github.com 免费注册一个即可。
获取 token（4 步）：
1. github.com 登录 → 右上角头像 → Settings
2. 左侧最下面 → Developer settings → Personal access tokens → Tokens (classic)
3. Generate new token (classic)，Note 随便填，Expiration 选 No expiration，勾选 gist
4. 点 Generate，把生成的那串字符复制，粘到下面
